# Simple-Python-Interpreter

This is a stack based python interpreter
\The interpreter has the ability for the user to input integers and strings and perform arithmetic operations as well as if and loop statements 

\Instructions: 
\When downloading the folder, there will be 4 different oll files that execute commands
\To run one of these files, type "python interpreter.py (filename)"

\Program 1 Reads 2 values and determines if they are equal or not
\Program 2 determines if a value is odd or even
\Program 3 Checks if a value is divisible by 3
\Program 4 is a simple calculator, it reads three values, the first two are the values, then the last value is a string that determines the operation
